# Results

This directory documents the outputs of the thesis experiments without redistributing institute-only robot geometry or third-party datasets.

Planned/appropriate result artifacts include:

- reachability-map screenshots for the four first-axis configurations,
- free-index comparison views,
- inverse-reachability visualizations,
- base-placement candidates,
- union-map cross sections for the ship-cutting task pose.

See [`../docs/results.md`](../docs/results.md) for the interpreted findings.
